# AirGuard release notes

## 3.0.0 — audited self-contained release (October 2026)

- Fresh independent timeout for the Vercel data service and direct-provider recovery.
- Strict calendar-time, provider-data and cached-response validation.
- Twelve-hour client forecast cache expiration; three-hour stored-data planning safety boundary.
- Current data fallback correctly labeled when using a nearby hourly model value.
- Browser test regressions for outage, malformed upstream and manual retry.
- Fixed mobile bottom navigation overlap and small-screen scrolling.
- Corrected local PNG serving, improved privacy disclosure, and formatted public-impact guide.
- Updated versioned service-worker shell, health endpoint and deployment instructions.
- Removed no working features; preserved AirTwin, Ask, Family Shield, Community Action, Methods, PWA and CSV.

## Earlier versions

2.3: Added JSON-safe Vercel API and direct-provider recovery. 2.2: Replaced marketing panels with charts and a formal interface. 2.1: Improved planning, question classification, saved plans, Urdu letters and local-data handling.
